Two craftable appliances, styled and balanced to sit alongside the base game's own. Because they are craftable, they don't need to be placed on a map to be useful.

This is a continuation of the original Vanilla Appliances Extended, which stopped working when build 42 landed and is no longer updated by its author. Build 41 script and Lua conventions did not survive the move, and most of this mod sat on them, so the appliances were rebuilt against what build 42 actually does rather than patched.

Pre-42 support is dropped deliberately rather than straddling both builds.

[b]Build 42.20 or newer. Singleplayer and multiplayer. Safe to add to an existing save.[/b]


[img]https://i.ibb.co/xtVSd8Kn/Steam-Workshop-Contents-Seperator.png[/img]

[b]Chest Freezer[/b]

A large freezer in the spirit of the icebox, two tiles wide, with two 100-slot frozen compartments rather than the icebox's 20.

It needs refrigeration components, which are salvaged rather than found. Pick up a fridge, then use the disassemble option on it in your inventory. A screwdriver and Electrical 3 are required.

If 100 per compartment is too much for your game, it is a sandbox option and can go as low as 1. The engine caps world containers at 100, so it cannot go higher.

[b]Potbelly Stove[/b]

A craftable alternative to the wood stove. It wants a lot of metal and welding gear, and it doesn't survive being moved especially well. Good for putting heat in a bedroom before winter does its worst.

It burns wood rather than running on power. To fuel it, open the stove and use the Destroy for Fuel button in the loot window, the same as any other fire in build 42. Right clicking the stove itself only offers to light or put it out.

[b]Extra dismantling[/b]

Toy cars, loose radio components and electric guitars break down for electronics scrap. The base game already handles TVs, radios and walkie-talkies on its own, so those are left alone.

[b]Options[/b]

Chest freezer capacity per compartment is a sandbox option, from 1 to 100, defaulting to 100. It is a sandbox option rather than a client setting so a server sets it for everyone instead of each player running their own numbers.

New freezers use the value as they are built. Freezers already standing in a save pick it up the next time the world loads, so changing it mid game works.

[b]Fixed on the way to build 42:[/b]

[list]
    [*][b]Both appliances were uncraftable.[/b] Build 42 replaced the old recipe format outright. It ships 969 craftRecipe blocks and no legacy recipe blocks at all.
    [*][b]The mod's server code raised on load[/b] and took the rest of its server Lua with it, because the namespaces its XP handlers were defined against no longer exist.
    [*][b]Dismantling a guitar did nothing.[/b] Build 42 consolidated the six coloured electric guitars into two items, so the recipe pointed at ids that no longer resolve.
    [*][b]Salvaging produced nothing[/b] from a misspelled item id.
    [*][b]The component tooltip never appeared.[/b] Build 42 reads translations as JSON.
    [*][b]Shoving an appliance deleted it,[/b] because entity health was never declared.
    [*][b]The appliances rendered over anything standing beside them,[/b] for want of tile geometry.
[/list]

[b]Known issue:[/b] you can stand in the far half of the chest freezer. Only the origin tile of a multi-tile object blocks movement in build 42, and a vanilla wood bed does exactly the same thing. Nothing this mod can change fixes it without dropping the freezer to a single tile and losing the two-compartment layout.
